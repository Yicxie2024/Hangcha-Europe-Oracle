Hangcha Sales Assistant v1.5.21
月度发运统计：当月筛选 + 人工复核 + 独立月报 + YYYY-MM 归档
===========================================================

【新流程】
主程序「其他功能」→「月度发运统计 / AI补全…」。
1. 选 YYYY-MM、业务周汇总 Excel（有「发货」子表）、发票 PDF 根目录。
2. 点「① 扫描当月发票」。此时仅扫描、显示列表，不创建月报。
3. 列表仅出现汇总 Excel 中能确定属于该月份的发票记录：
   - 正常：Excel 中发票金额=Netto，PDF 编号/日期/金额一致，非瑞士，有可识别的货物。
   - 待复核：部分货物无法识别、VAT/客户缺失、PDF 缺失、编号或金额不一致等。
   - 不符合条件：Excel 金额不一致、已明确瑞士目的地等。
   - 已确认：由用户右键确认，只纳入 PDF 中正确识别的商品行。
   - 已移除：不参与本月份月报，允许右键恢复。
   - 来源已变化：保存决定后来源 PDF 或关键汇总数据变化，需要重新复核。
   不能确定日期属于当前月份的记录不显示；若汇总表缺失发票日期，应先完善汇总数据。
4. 右键可「打开原始 PDF」「查看识别明细」「复核确认」「移除」「恢复自动状态」。
   - 仅当原始 PDF 的发票号、日期、Total/Netto 和非瑞士目的地通过核对，
     且至少识别一条有效货物行时，才允许复核确认。
   - 确认部分识别时，未识别行完全不进入报表；请核实整张发票总额与
     成功识别货物金额可能不一致的情况。原始发票金额绝不会被重算或改写。
   - 找不到 PDF 或 PDF 身份/金额不一致时不能强制纳入；可移除或修正来源重新扫描。
5. 点「② 导出月报 + AI 文件」。未确认的待复核单默认不纳入；软件会提醒。

【输出目录】
在选中的“导出根目录”下自动创建对应年份月份，如：
  月度发运统计/2026-10/
    Versendungsstatistikmeldung_2026-10.xlsx
    Versendungsstatistikmeldung_2026-10_半成品.xlsx
    ChatGPT_补全Prompt_2026-10.txt

- 独立月报 xlsx：仅一个「10月」工作表，A–S 列；不包含 AI、筛选日志、说明页。
- 半成品 xlsx：「10月」「AI待补全」「筛选日志」「历史参考」「说明」。
- 不再把“仅公司内部统计：只纳入非瑞士……”文字写在月度统计主表。
- 旧版本导出不会静默丢失：同月再次导出会自动备份到该月份的 _历史版本 文件夹。
- 所有月报数据按发票分组，第一行包含整张发票的运费/Netto；每货物一行。

【AI 补全与导回】
点击「导入 ChatGPT 补全结果」时，文件选择框默认进入当前 YYYY-MM 文件夹，
并自动选取该文件夹内的原始半成品（找不到时提示手动选择）。
AI 返回文件只允许通过「AI待补全」G/H/I 任务ID回填 P/Q/R/S 重量、体积；
发票编号、配件、日期、金额、数量都不会从 AI 文件覆盖。
导入通过后自动保存：
  Versendungsstatistikmeldung_2026-10_AI补全待复核.xlsx
  Versendungsstatistikmeldung_2026-10_AI补全待复核_导入核验.txt
并同步更新独立的 Versendungsstatistikmeldung_2026-10.xlsx。
AI 估计值仍需人工确认，未实际测量的数据不得标记为实测。

【复核决定持久化】
按 YYYY-MM、发票号和原始数据指纹保存复核决定，重启和重新扫描会自动恢复。
保存位置：%LOCALAPPDATA%/HangchaSalesAssistant/monthly_invoice_review.json
本地配置及已确认重量尺寸仍沿用之前的位置。
若汇总表关键信息或 PDF 内容变化，旧的确认/移除决定会标记“来源已变化”，
必须重新复核/恢复自动状态；扫描后到导出前如来源发生变化也会被拦截。

【兼容性及注意事项】
- 原始业务周汇总 Excel、PDF、库存 Excel 均只读，不会被这个模块覆盖。
- 文件名包含「作废」的发票不参与索引；「有误」不能未经校验纳入。
- 无法可靠识别部分货物，只能输出已识别项；无法可靠识别整张发票身份时不可人工放行。
- 当前不读取物流单中的实际包裹重量或体积，需要 AI/人工补全。
- 试运行请先选 2026-10，核对扫描摘要和独立月报中的每张发票。
- 已在模拟 Windows 窗口尺寸 840×570 和后台扫描流程测试；真实公司电脑需要现场验证。
