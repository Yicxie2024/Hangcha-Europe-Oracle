Hangcha Sales Assistant v1.5.18 — 统一库存查询按钮可视化优化
=====================================================
适用：Windows 版 v1.5.17 原有「统一库存搜索与拣货单」界面。

本版变化：
1. 彻底移除居中查询按钮中的特殊 Unicode 向下箭头字符，修复 Windows/Tkinter
   默认字体缺少字形、显示两个带问号方框的现象。
2. 查询按钮改为深青色 Canvas 自绘控件；「查询库存」文字居中显示，
   下方用线条与实心三角形绘制真正向下的箭头，不依赖任何图标字体或额外图片。
3. 鼠标悬停时变深，按下时反馈；支持 Tab 获取焦点，Enter/空格执行查询。
4. 按钮固定于「① 待搜索清单」和「② 库存查询结果」的中间；
   右侧简短文字明确说明上方和下方各自用途。
5. 整理旧版错误提示，将「搜索全部」统一改为「查询库存」。

兼容与安全：
- 仅修改 gui_picking_ui.py 的界面绘制和按钮交互，不改订单识别算法、
  库存索引、数量补录、Excel、PDF、打印规则、SQLite 或 Teams 模块。
- 无需安装新 Python 第三方依赖，也无需额外字体文件。
- Linux Xvfb/Tk 在 930×570 非最大化窗口测试：箭头显示正常，按钮和
  删除/清空按钮不越界，鼠标及键盘触发查询回调正常。
- 尚未在实际 Windows/打印机环境中进行 GUI 试用；建议先重启程序检查。

安装：
A) 如果已安装 v1.5.17，退出所有 Hangcha 程序，先备份原程序目录。
   将 v1.5.18 增量补丁解压到原程序文件夹，覆盖同名文件，再运行 10_START_GUI.bat。
   不必运行 01_INSTALL.bat，也不要删除 .venv、数据库或个人配置。
B) 新安装或希望完整升级：使用 v1.5.18 Full_Windows 完整包。
   按 README_START_HERE.txt 操作。
