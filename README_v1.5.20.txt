Hangcha Sales Assistant v1.5.20 — 按业务周汇总 Excel 发票号生成月度内部统计
=======================================================================

升级内容
--------
替换了 v1.5.19“逐份 PDF 自行筛选发票”的逻辑。现在以业务周汇总 Excel 的「发货」子表为候选发票的唯一筛选索引。

新流程（仅读取，绝不修改业务周汇总 Excel 和原发票）
--------------------------------------------------
1. 主界面「其他功能」→「月度发运统计 / AI补全…」。
2. 选择 YYYY-MM，例如 2026-10。
3. 【必选】选择现有业务周汇总 Excel（包含「发货」子表）。
4. 选择存有发票 PDF 的根目录，可包含客户和日期子目录。
5. 可选历史月报参考和库存重量尺寸参考；选择输出目录。
6. 点击「生成半成品 Excel + AI Prompt」。
   - 从 Excel「发货」表 C「发票号」取得要查找的发票编号。
   - 同月依据发票日期（优先 I 列「发票发送日期」，其次 G/F；对原软件生成的发货表，F/G/I 均为 Invoice date）。
   - 读取 D「发票金额」和 E「Netto」，要求静态金额精确相等且都大于零。
   - 仅对符合条件的编号在 PDF 文件名中查找；若文件名无编号/错误编号，必要时读取未匹配 PDF 的页眉补查。
   - PDF 中 Invoice No. / Invoice date / Total / Netto 与 Excel 一一核对。
   - 排除目的地为瑞士的订单；其他国家且 PDF 信息可靠的订单纳入。
7. 输出 Versendungsstatistikmeldung_YYYY-MM_半成品.xlsx 和
   ChatGPT_补全Prompt_YYYY-MM.txt。
8. 查看「筛选日志」；上传半成品 + Prompt 给 ChatGPT；回软件使用「导入 ChatGPT 补全结果」。

异常处理
--------
- 找不到 PDF：待复核；不编造或自动纳入。
- PDF 编号、日期或金额与 Excel 不一致：待复核；不自动纳入。
- Excel 出现重复发票号、金额缺失/为0、F/G/I 日期冲突：待复核。
- PDF 同发票号不同文件版本：待复核；内容完全相同的副本去重。
- PDF 瑞士目的地：排除；目的地不明确：待复核。
- PDF 中无法识别商品明细、客户名称或客户 VAT No.：待复核。
- Excel 不符合软件的「发货」表头：停止操作，提示预期表头。
- 软件读取源文件均为只读，现有「订单」「发货」子表和原始 PDF 一律不更改。

未变化的功能
------------
- 报表继续沿用原月度表 A-S 结构；不沿用旧表失效的跨文件折扣公式。
- 历史重量/体积作为参考，经人工确认的数据可以自动复用。
- ChatGPT 只允许补「AI待补全」G/H/I 三列；导入过程验证任务ID及字段，
  即使 AI 修改了财务数字，也不会覆盖原半成品的财务数据。
- 仍是公司内部统计，不是正式 Intrastat。

安装方式
--------
现有 v1.5.19：关闭软件 → 备份整个程序目录 → 将 v1.5.20 增量补丁的同名文件
解压覆盖原目录 → 运行 10_START_GUI.bat。不需要删除 .venv、SQLite、state 和个人配置。
新机器：解压完整包 → 01_INSTALL.bat → 10_START_GUI.bat。

测试范围
--------
已使用真实丹麦/奥地利/德国内销发票及符合原「发货」表结构的测试 Excel 验证：
月份和金额筛选、匹配 PDF、PDF 内容校验、缺文件、重复发票/副本、金额差异、
不含发票号的文件名回退匹配、瑞士排除、月报及 AI 安全导入、小窗口 UI。
实际的业务周汇总工作簿没有在本次附件中提供；请在 Windows 上用原工作簿
进行一次只读试运行，核对筛选日志及发票数量。
