HCE Oracle v1.5.32 | 拣货单排版更新
===================================

改动范围：仅 PDF 拣货单模板与界面版本号；仓库路径、ERP/Part 匹配、Excel 和 SQLite 数据不改变。

1. 删除表内的“确认”列，改为表格最左边留白处的可手写打钩方框；无额外表格列。
2. 删除主标题下的路线说明、多库存解释、配件种类三行。
3. 库存来源仅保留文件名，不再显示括号中的提示语。
4. 相同序号在同一物理楼层的多条库存记录，纵向合并序号、应拣、备注；各条源Excel记录仍分别显示库位和库存。
5. 同一配件重复库存记录采用浅红色底纹，跨物理楼层重复时每个楼层均加注“同一配件跨物理楼层重复（3F、1F）”等。
6. 有明确零库存的记录或没有对应库存记录的配件，使用浅橙色底纹，优先于浅红；未知库存不等于零库存。
7. 合并行设置 NOSPLIT，防止重复行跨页被拆开；长表仍保留自动分页及表头重复。

安装：关闭程序。建议备份原目录，再将补丁文件覆盖当前 v1.5.31 程序目录，重新运行 10_START_GUI.bat。
提示：打印手工确认框而非可点击 PDF 表单字段，便于纸质拣货单现场勾选。
