Hangcha Sales Assistant v1.5.28 — G/H 特殊库位 01–08 更新
=====================================================

相对于 v1.5.27 的修改：
1. G/H 两列的有效库位行号更新为 01–08（G/H01 距楼梯口最近，G/H08 最远）。
2. 解析、库位异常提示、路径图增加 G/H08 的有效路线节点。
3. 横向通道仍位于物理行 05 和 06 之间；楼梯出口与通道相连。
4. 三楼→二楼→一楼的拣货顺序、多库存行合并编号、连续 A4 自动分页保持不变。
5. 原库存 Excel 不会被修改，不进行任何自动扣减。

旧版对 G/H08 的误判已修正。对 G/H09 及更大编号，因目前规则没有确认实际位置，
仍标记为位置待核；如能识别物理楼层，仍列在对应楼层末尾。

安装：关闭软件并备份目录，把增量补丁的文件覆盖到现有安装目录，
再次运行 10_START_GUI.bat。使用旧于 v1.5.27 的版本时请选择完整安装包。
