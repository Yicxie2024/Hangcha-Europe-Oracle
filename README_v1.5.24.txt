Hangcha Sales Assistant v1.5.24 - 拣货单三层连续排列 + 自动分页
=============================================================

本次只修改 A4 拣货 PDF 的排版与程序版本号，不改变 v1.5.23 的仓库路线、库位识别、库存查询、订单识别、Teams 或月报逻辑。

改动说明
--------
1. 不再在 3F、2F、1F 或“无法确认区域”之间强制分页。
2. 按 3F -> 2F -> 1F -> 无法确认区域的顺序连续输出；某楼层没有条目时不输出空区块。
3. 只有当前 A4 页面剩余空间不够时才换页，长表格自动跨页；跨页时重复列表表头。
4. 新楼层标题与首条拣货行尽量留在同一页，避免页尾孤立标题。
5. 优化表格上下内边距与楼层间距，减少只为签名区多印一页的情况，同时保留实拣/确认/备注等全部列。
6. 仍然生成每订单一个 PDF，不会按楼层拆成多个文件。不会自动打印、修改或扣减 Excel 库存。

沿用的关键业务规则
----------------
- 楼层顺序三楼 -> 二楼 -> 一楼，同楼层通道路径排序，同货架位置从高到低。
- 有效五字符库位前缀正常归层；多个库位完整展示，不复制总需求量到每个位置。
- A01 等缺少层号的库位按约定放在一楼末尾；无法确认楼层的条目放最后，统一表格列。

安装
----
已装 v1.5.23：退出软件，备份当前程序目录，解压本次补丁覆盖同名文件，运行 10_START_GUI.bat。
其他版本：使用本次完整 Windows 包。
不需要清除原配置、归档记录或历史数据。

测试
----
1) 人工混合楼层、部分库位与异常库位 10 条拣货记录：三楼/二楼/一楼/异常区连续排在同一张 A4；签名区也在同一张。
2) 模拟 90 条多楼层记录：自动分页，续页重复列表表头，楼层标题未被留在页尾。
3) 读取实际库存表的多库位记录，仍显示全部位置且不重复分配需求。
4) 通过 Python 语法编译和 PDF 页面渲染检查。
未进行公司 Windows 打印机实测。
