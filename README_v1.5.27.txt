Hangcha Sales Assistant v1.5.27 — 05/06 通道 + G/H 特殊库位更新
==============================================================

本版基于 v1.5.26，严格限定为仓库库位解析和路线模型更新。

1. 横向通道更正为普通矩阵第 05 与第 06 行之间（原 06/07 作废）。
2. 楼梯出口位于 G/H 附近，直接连通 05/06 横向通道。
3. G、H 列不按其他列普通行号处理：G/H01 最近楼梯出口，
   G/H07 最远；G01–G07、H01–H07 都是合法库位。
4. G/H 的编号 08–12 不再被误认为合法库位；如果货架层号可识别，
   保留在所属物理楼层末尾供人工核查，不伪造可通行路线。
5. A–F/I–P 仍采用普通矩阵 01–12 行；货架层号 01–04 为一楼，
   05–08 为二楼，09–12 为三楼。
6. 拣货单仍保持 3F → 2F → 1F 连续排版/自动分页；相同位置
   货架从高到低；同 SKU 多条 Excel 原始库存记录分行显示并使用同一序号。
7. 线路是未量测的启发式通道图，非承诺实际最短路径；实际现场路宽、
   端部可通行关系及 G/H 两列间连接尚未做现场验证。

安装方式：已安装 v1.5.26 用户关闭程序，备份旧安装目录，
将本版增量补丁解压至原程序目录覆盖同名文件，然后运行
10_START_GUI.bat。其他版本建议使用完整 Windows 版。

安全：不写入库存 Excel，不修改其他业务数据，不自动扣减库存。
