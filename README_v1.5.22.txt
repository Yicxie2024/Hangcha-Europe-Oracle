Hangcha Sales Assistant v1.5.22 — Warehouse Path / Picking List
===============================================================
本版在 v1.5.21 之上更新“库存搜索 → 拣货单”，其他功能保持不变。

安装
----
已有 v1.5.21：先关闭软件，备份旧目录，再把 v1.5.22 增量补丁解压到原文件夹并覆盖同名文件，运行 10_START_GUI.bat。
新电脑：解压完整版本，按 README_START_HERE.txt 完成初次安装。

实物仓库模型（用户确认）
--------------------
* 3 个物理楼层，各楼层 16 列 (A–P) × 12 行 (01–12)。
* 库位编号 A0103 = A 列、01 行、货架层号 03 = 物理一楼、相对层号 3。
* 库位层号 01–04 → 一楼，05–08 → 二楼，09–12 → 三楼。编号越大，货架越高。
* 06 与 07 行之间有横向通道；G/H 列的 01–06 行为楼梯区域，没有可自动定位的货架。
* 楼梯出口直接连接 G/H 附近的 06–07 横向通道。
* 每层 01 行一侧可进入货架列，且路线可通过 06–07 横向通道跨列。

本次拣货路线调整
----------------
1. 物理楼层按三楼→二楼→一楼输出，每个有任务的楼层单独成页。
2. 每层从 G/H 楼梯横向通道出发并作为暂定终点。库位先通过通道图排序，不再按字母/货架高度进行全局硬排序。
3. 到同一个矩阵位置后，同一货架层号按高→低处理，再按货架格、后缀排列。
4. G/H 的 01–06 不走自动路线。没有完整定位或格式特殊的库位，优先按可以确定的物理楼层放到对应页的“候选库位/人工确认”栏。
5. A01 等只有字母+行号的库位按使用者指定的业务约定暂放一楼的人工确认栏末尾，且明确标注“真实楼层待核”；不能作为已验证位置自动寻路。
6. 多个库位会全部列出候选位置；库存 Excel 只提供合计库存时，不自动把合计拆给多个位置，防止重取货。
7. 路线的通道权重只是未现场测量的步行代价近似值，不提供虚假的实际米数或承诺全局最短路径。未确认的出口方向、障碍、托盘作业情况仍需现场核实。

注意
----
* 本版只读查询原 Excel，不自动修改库存，不做锁库/自动扣减。
* 适用于从原程序直接生成的 A4 Landscape PDF 预览与打印。
* 打印前必须先确认库存快照、候选库位和预期实际拣货数量。
* 本版尚未在真实 Windows 仓库现场/打印机验证。建议先在少量订单上打印预览测试。
