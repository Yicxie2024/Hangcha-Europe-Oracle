Hangcha Sales Assistant v1.5.15 - 批量库存搜索与 A4 拣货单
=========================================================

本版在 v1.5.14 的 PDF/Excel/归档/Teams 基础上增加：

1. 订单拣货单与可选关联发货单打印
   - 识别结果 -> 订单行 -> 右键「打印此订单拣货单及发货单…」；
     或「库存搜索」->「订单配件位置查询」-> 选择订单。
   - 软件读取订单 PDF 的 Qty./ERP No./Part No.，从库存 Excel 查库位；
     只读，不修改任何业务 PDF/Excel、不会预留或扣除库存。
   - 生成 A4 横向 PDF：合同号、客户、Rack No.、ERP No.、Part No.、
     描述、需求量、库存、实拣空栏和核对框。按楼层和走位排列。
   - 无法定位到标准货架、数量不足、编号冲突的项目，在 PDF 下方
     单独标成「人工确认」，并保留原始 Excel 的 Rack No.、库存及配件编号。
   - 只从完成扫描的发货单 PDF `Ordernumber` 关联同一合同；
     `Delivery No.` 仅用来标识发货单自身。若一单多张发货单，在
     打印对话框逐张勾选。拣货单、每张发货单的打印份数可分别输入。
   - 确认对话框 Enter 提交；Esc 取消；默认只生成/预览，不自动打印。

2. 批量库存搜索
   - 打开「▦ 库存搜索」默认进入「批量查询与拣货单」标签。
   - 输入 ERP 或 Part No.，以英文/中文逗号、分号分隔多个编号；
     也支持 CODE*2 表示该项数量是 2，未写数量使用旁边默认需求量。
   - 「添加」放进待搜索清单，可选中编辑需求量、删除或清空。
   - 「导入 Excel…」：支持 .xlsx/.xlsm，使用第一个工作表。
     推荐表头：ERP No. / Part No. / Qty.（三列），或 Code / Qty.
     （两列），每行至少一个编号和一个大于零的需求数量。
     无表头时支持 A=编号、B=数量。导入有无效数量时整体停止，
     显示异常行号，不会部分添加。
   - 「搜索全部」后展示匹配库存、编号、Rack No.、状态等；
     双击行看所有匹配库位，单击「打印」列可将项目剔除/恢复，
     被剔除项目不会进入本次拣货单。
   - 自动合并同一配件的重复需求；有多个不同 ERP/Part 组合则
     显示「编号冲突·待核」，不能虚构可用数量。

3. 拣货路径配置 (可用作相对路线规划，不代表测量距离)
   - 货架列 A..P，从近到远；货架行 01..12，从近到远。
   - 货架编码 A020304 -> A列、02行、03层、04格。
   - 层 01..04 = 1F, 05..08 = 2F, 09..12 = 3F。
   - 可从每列第 1 行进入；第 6/7 行之间允许横向跨列；
     G/H 列第 6 行附近有楼梯。默认按楼层打包，楼层内采用
     基于通道网络距离的启发式路径；并非严格全局最优解。
   - 非 A-P 标准库位（例如 Y0101/Z130103）始终保留原样供人工核对，
     不会被错误地投射到 A-P 货架。

4. 打印机与安装
   - 运行 01_INSTALL.bat 更新 PDF 生成依赖 reportlab。
   - 为了可靠地按指定份数直接打印 PDF，请额外安装 SumatraPDF
     (https://www.sumatrapdfreader.org/) 并在 Windows 设置好默认 A4 打印机。
     软件会自动寻找 SumatraPDF.exe（PATH/Program Files/LocalAppData）。
   - 未安装 SumatraPDF 时，仅打开拣货单与已选发货单，提示在 PDF
     阅读器手动打印；不会假称已完成打印、也不会忽略份数偷偷打印。
   - Print 确认只有你点击或按 Enter 后才开始，Esc 可直接取消。
   - 打印历史保存在当前用户：
     %LOCALAPPDATA%\HangchaSalesAssistant\picking_print_history.sqlite3
     仅在打印程序返回成功后登记“已提交”，并非打印机已实际出纸。
   - 生成的拣货单 PDF 默认保存：
     %USERPROFILE%\Documents\Hangcha Picking Lists
   - 请保留原本的 state、用户配置和 .venv，不清理 SQLite。

注意
- 库存来自 Excel `库存已有备件` 工作表 MA 列缓存，不是实时 ERP。
- 打印前如果库存源 Excel 或订单 PDF 改动，要求重新查询；
  发货单源文件也要和本次完整扫描时的指纹一致。
- Excel「订单/发货」新增、安全确认、备注、归档、Teams 上传模块完全不变。
- 未在实际公司 Windows 11 与实体打印机上进行试印；请先用 1 份打印测试。
