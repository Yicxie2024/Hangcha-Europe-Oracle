Hangcha Sales Assistant v1.5.4  |  表格精简 + Excel 订单备注
================================================================

本版仅改变 GUI 表格显示方式和备注读取，不改变 PDF 解析、Excel 写入、
归档、定时任务、Teams 拖拽上传等功能。

更新内容：
1. 将「合同号」「发票号」合并成「合同号 / 发票号」一列：
   - 合同父行 / 订单 PDF：显示杭叉合同号（Order No.）
   - 发票 PDF：显示发票号（Invoice No.）
   - 其他 PDF：在有可靠编号时显示对应编号
   - 继续以杭叉合同号关联父子行，显示上的合并不改变内部匹配。
2. 删除「PDF 文件名」列；右键“打开 PDF”“在文件夹中显示”仍可使用。
3. 增加「备注」列：只读查看所选 Excel 的「订单」工作表 G 列。
   依据订单工作表 B 列的合同号匹配；主订单（合同）行显示备注，
   发票等子文件不重复显示该备注。
   - 备注为空时显示空白。
   - 备注较长时表格显示简略文本，选中合同后展开「选中记录说明」查看完整内容。
   - 同一合同有多条订单且备注不同，会显示“多行备注不一致，请核对 Excel”。
   - 所选 Excel 不存在时，备注列留空；读取失败时显示提示。
   - 本地尚未写入的“待写备注”草稿不会冒充已经存在于 Excel 的备注。
   - Excel 更改或切换目标文件后，下次界面刷新（扫描、核对、排序等）重新读取。
   - 仅读取 Excel ZIP/XML 数据，不启动 Excel COM，不保存或改写 Excel。
4. 「识别结果」和「归档管理」保持相同列布局，原有树形结构不变。

升级方法：
- 退出正在运行的 Hangcha Sales Assistant，备份当前程序目录。
- 将 gui.py、gui_excel_notes.py 放入程序根目录（例如 C:\Hangcha Assistant）。
- gui.py 替换原文件，gui_excel_notes.py 为新增文件。
- 保留个人配置、归档状态、备注草稿数据库和业务 Excel。
- 双击 10_START_GUI.bat 重启。无需重新安装 Python/依赖。

如已有 Excel 正在人工编辑，需先保存文件才会显示新备注。
如因 OneDrive 同步或文件损坏无法读入备注，GUI 只提示，不会尝试修改或覆盖。

测试：v1.5.3 完整包所含 107 项现有测试 + 6 项新增测试通过。
本地使用真实“业务周汇总表_XYC_更新至26.10.2026.xlsx”验证备注读取，
但 Windows 本机外观仍需最终验收。
